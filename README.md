# Dim Veil / 暗幕

[![Android CI](https://github.com/h166278/dimveil/actions/workflows/android.yml/badge.svg)](https://github.com/h166278/dimveil/actions/workflows/android.yml)

A privacy-first Android dim overlay that visually goes beyond the system minimum brightness. It uses a touch-through pure-black overlay and never changes system brightness.

## Privacy

- No network permission, advertising, analytics, account, cloud sync, or tracking.
- No screen-content reading, gesture injection, auto-clicking, or input monitoring.
- Optional accessibility overlay is used only to render the dim layer.

## Build

GitHub Actions is the supported build path. Every push runs unit tests and produces a debug APK artifact.
