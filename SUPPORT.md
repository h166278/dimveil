# Support

## Usage questions

For setup or expected-behavior questions, first read the [README](README.md), [troubleshooting guide](docs/troubleshooting.md), and [limitations](docs/limitations.md). Then use a GitHub Discussion or a feature request issue when enabled.

## Bug reports

Use the Bug Report form. Include a reproducible sequence, device model, Android/ROM version, requested depth, active overlay path, and whether touch-through worked. Redact personal data from screenshots and logs.

## Compatibility reports

Use the Compatibility Report form for device-specific results. The maintainer adds sufficiently detailed, reproducible reports to the public compatibility matrix.

## Security issues

Do not use public support channels. Follow [SECURITY.md](SECURITY.md).
