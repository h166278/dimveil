# Vocabulary

## Core switch

The central circular control that starts or stops the dim overlay. It is not a system brightness control.

Discouraged aliases: power orb, brightness button.

## Visual direction

The supplied reference's hierarchy, spacing, restrained color semantics, and central-control emphasis. It does not mean copying pixels, third-party art, or intellectual property.

## Status panel

An un-nested surface that reports the currently available coverage path and permission readiness.
