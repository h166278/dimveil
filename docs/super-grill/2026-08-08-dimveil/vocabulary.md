# Vocabulary on Probation

| Canonical term | Definition | Discouraged aliases |
| --- | --- | --- |
| 遮罩 | 纯黑、触摸穿透的窗口覆盖层；不更改系统亮度。 | 降亮度、负亮度、滤镜 |
| 普通覆盖 | 由用户授权的应用悬浮窗覆盖层。 | 全屏权限、系统覆盖 |
| 增强覆盖 | 用户启用无障碍服务后使用的无障碍覆盖层，仅用于渲染遮罩。 | 无障碍模式、自动化模式 |
| 遮罩深度 | 黑色遮罩不透明度的 0–90 整数百分比。 | 亮度值 |
| 光能守卫 / 暗影守卫 | 原创状态视觉，分别表示遮罩关闭 / 开启。 | 任何现有角色名称 |
